## A. Anna zgłasza pracownię druku 3D

**Tekst do wklejenia w obu formularzach**

> Przykład pokazowy. Prowadzę w technikum szkolną pracownię druku 3D. Uczniowie projektują w CAD i drukują organizery oraz uchwyty do lekkich przedmiotów dla mieszkańców domu pomocy społecznej. Pracownicy DPS uzgadniają z uczniami potrzeby i sprawdzają użyteczność prototypów. W pilotażu wytworzyliśmy 18 pomocy, a po czterech tygodniach 15 nadal było używanych. Chcemy powtórzyć program w drugim technikum i sprawdzić, ile pomocy pozostanie w użyciu po czterech tygodniach.

## Uruchomienie i powrót do początku

Z katalogu repozytorium uruchom:

```bash
scripts/demo/prepare.sh
```

Polecenie na pierwszym uruchomieniu zapisuje migawkę bazy po T13 połączeniem tylko do odczytu, a następnie odtwarza z niej bazę `radar_t14_demo`. Kolejne wykonanie przywraca tę samą migawkę i wyjściowy cache źródeł. Ustaw `T14_SOURCE_CACHE`, gdy cache po T13 jest poza sąsiednim `radar-inowacji/data/cache`. Pliki lokalne są domyślnie w `~/.local/state/wihajster-t14`. Do przygotowania potrzebne są PostgreSQL z pgvector, narzędzia klienta PostgreSQL i zapisany cache źródeł.

Jeśli serwery pokazu nie działają, uruchom w dwóch terminalach:

```bash
scripts/demo/serve.sh api
scripts/demo/serve.sh web
```

Reset zrób między próbami, po zakończeniu importu i zapisów operatora. Następnie odśwież stronę i wybierz Annę do A lub Katarzynę do pierwszej części B. Po resecie nowa karta szkoły i nowo wykryty projekt wrócą do aplikacji dopiero po przejściu scenariuszy. [Start](http://127.0.0.1:5174/)
